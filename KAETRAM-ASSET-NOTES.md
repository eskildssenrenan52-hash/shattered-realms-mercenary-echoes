# Kaetram: origem, licença e uso de assets

Fonte consultada: [Kaetram-Open no GitHub](https://github.com/Kaetram/Kaetram-Open). O pacote já presente em `public/kaetram/` declara ter sido copiado do commit `f5b6665ef035ba79816458b92cbe77204042a318` e contém o catálogo local de sprites em `src/odyssey/kaetram-sprites.json`.

O README upstream informa que os assets são licenciados sob CC-BY-SA 3.0. O repositório também distribui o código sob MPL-2.0 e um aviso adicional OPL. O OPL exige link direto para Kaetram na seção de créditos, preservação dos créditos dos criadores e continuidade do código aberto; também proíbe usar o projeto ou qualquer parte dele para trabalho relacionado a IA sem permissão direta dos criadores. Os textos de licença copiados estão em `public/kaetram/LICENSE` e `public/kaetram/LICENSE_OPL`.

O jogo mantém o link para Kaetram em `public/game-credits.txt`, aberto a partir da tela inicial. Assets copiados podem ser usados no jogo respeitando a atribuição e os termos aplicáveis. Arte nova gerada por IA deve ser criada a partir de prompts independentes: não usar sprites, código, folhas ou imagens do Kaetram como referência, entrada ou material de adaptação para geração por IA.
